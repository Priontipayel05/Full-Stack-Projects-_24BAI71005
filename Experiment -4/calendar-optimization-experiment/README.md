# Calendar Optimization Experiment

## Experiment 4.2: Optimizing Rendering Performance and Testing Strategies

### 📋 Overview
This experiment demonstrates performance optimization techniques in React applications by building an interactive calendar with event management features.

### 🎯 Objectives
1. Understand performance bottlenecks in UI systems
2. Optimize rendering using memoization techniques
3. Reduce unnecessary re-renders in React applications
4. Implement testing for UI components and application logic

### 🚀 Features
- Interactive Calendar View
- Event Management (Add, View, Delete)
- Search Functionality
- Date Filtering
- Performance Optimization (React.memo, useMemo, useCallback)
- Unit Testing (Jest + React Testing Library)

### 🛠️ Technologies
- React.js
- React.memo
- useMemo & useCallback
- Jest
- React Testing Library
- CSS3
