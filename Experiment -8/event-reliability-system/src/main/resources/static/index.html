Reliability Features

1. Retry Mechanism

Failed events are retried up to three attempts.

2. Exponential Backoff

Retry delays increase from 500 ms to 1000 ms.

3. Idempotency

Repeated event IDs are rejected to prevent reprocessing.

4. Dead Letter Queue

Events that exhaust their retries are retained for inspection.
